## 🚀 Projeto em destaque

### Customer Churn Prediction — Conecta Brasil Telecom

Projeto educacional de Machine Learning para simular a previsão de cancelamento de clientes de uma empresa fictícia de telecomunicações.

**Principais funcionalidades:**
- Preparação e análise de dados sintéticos.
- Treinamento e avaliação de um modelo de Regressão Logística.
- Ajuste do limiar de classificação.
- Visualização de métricas e interpretação de previsões.
- API REST desenvolvida com FastAPI.
- Testes automatizados e integração contínua.
- Conteinerização com Docker.

**Resultados no conjunto de teste sintético:**

| Métrica | Resultado |
|---|---|
| Acurácia | 76% |
| Precisão | 28% |
| Recall | 53,85% |
| F1-score | 36,84% |
| ROC-AUC | 0,7465 |

**Limitação:** o projeto utiliza dados sintéticos e não foi validado com clientes reais.
